# Project Glowing Heart v0.8 Bridge Card

## What changed since v0.7

The project now generates a bridge document between Core artifacts and the Godot Observatory ecosystem.

## What this proves

Humans and future agents now have a single location describing the relationship between the two systems.

## What this does not prove

No parity.
No shared execution.
No transport equivalence.
No closure equivalence.
