# Project Glowing Heart v1.4 Shared Fixture Instance

## What changed since v1.3

The project now has the first shared fixture instance candidate conforming to the v0 preview schema.

## What this proves

The bridge can express one Core fixture and one Godot fixture candidate in a shared neutral vocabulary.

## What this does not prove

No parity.
No runtime equivalence.
No shared execution.
No closure equivalence.
No transport equivalence.
No pixel comparison.

```bash
python3 tools/glowing_heart_shared_fixture_instance.py
```
