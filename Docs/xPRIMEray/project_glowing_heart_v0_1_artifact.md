# Project Glowing Heart v0.1 Artifact

## What exists now

- `XPrimeRay.Core`
- `XPrimeRay.Testbench.Cli`
- `Fixtures/glowing_heart_minimal.json`

## What this proves

The repository now contains a pure C# Core project and a headless CLI harness that can load a fixture and emit validation-style output without Godot.

## What this does not prove

This v0.1 artifact does not yet prove hermetic closure, optical transport correctness, GRIN behavior, wormhole transport, or fixture equivalence with Godot.

## Why this is valuable

It creates the first non-Godot execution path while preserving the existing Godot harnesses.
