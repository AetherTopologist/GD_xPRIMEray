# Epistemic Airlock

**Project Optical Closure · Language Safety Framework**

This page is for the visitor who arrived via a question about portals, hidden geometry, mystery
spaces, or non-Euclidean physics. Welcome. The simulation has something honest to tell you.

## Six epistemic tiers

Every claim on this site belongs to exactly one tier. The tier is always labeled.

| Tier | Meaning | Example |
|---|---|---|
| **Established Mathematics** | Derived from proven theory. Not measured. | Spherical UV from atan2/asin; GRIN refraction gradient |
| **Implemented Engine Behavior** | How the code actually behaves. Reproducible. | The transport loop curves rays through the GRIN field |
| **Validated Fixture Output** | A committed measurement from a pinned fixture run. | Glowing Heart evidence chain; OC-001 observer sweep table |
| **Experimental Interpretation** | An observation about what the simulation shows. Bounded. | The probe region is not sampled by this observer at this distance |
| **Lore / Artistic Inspiration** | MisterY Labs mythology and creative framing. Not promoted to a higher tier without evidence. | Portal imagery; the bee sigil; non-Euclidean space as metaphor |
| **Open Questions** | Things the simulation cannot answer. Named honestly. | Whether this corresponds to any physical phenomenon |

## The honest answer to "does this prove...?"

If your question is: *"Can a bent light path hide a surface from an observer?"*

The simulation answers: **yes, under the declared transport parameters.**

If your question goes further — *"Does this prove hidden geometry exists?"* or *"Is this a real
portal?"* — the simulation has something honest to tell you: **those further questions remain open,
and this simulation is not evidence for them.**

The simulation shows you what the transport model does. The transport model is GRIN optics applied
to a declared scene. What that corresponds to in physical reality is a genuinely open scientific
question, and one that this project does not claim to answer.

## The boundary between curiosity and conclusion

Curiosity is welcome here. Conclusions are earned.

The project deliberately names the boundary between "what the simulation shows" and "what that
means." This is not a disclaimer — it is a design principle. The boundary is where the most
interesting questions live.

MisterY Labs treats lore, mythology, and mystery as **inspirations for measurable experiments**,
not as conclusions to be validated. The bee navigates by polarized sky and perceives beyond the
human visible spectrum. The experiment asks: can we build an observer, a geometry, and an optical
setup inspired by that question?

## What this project is not

- Not proof of hidden dimensions.
- Not proof of portals.
- Not a "first-ever" discovery (unqualified claims of this kind are not made here).
- Not conspiracy validation.
- Not mystical certainty.
- Not a claim that the simulation output corresponds to physical reality beyond the simulation.
