# Project Glowing Heart and the Observation Atlas

Project Glowing Heart is the protocol heart. The Observation Atlas is the map of observer systems that the protocol may eventually describe.

Project Glowing Heart provides the emerging protocol layer for describing fixtures, observers, snapshots, measurements, artifacts, and future comparisons. The [Observation Atlas](../Observatory/Observation_Atlas/README.md) places that work within biological, optical, scientific, computational, rendering, and educational observer families.

The architecture vision file remains a task-brief wrapper, so this note provides the repository link without rewriting that source.
