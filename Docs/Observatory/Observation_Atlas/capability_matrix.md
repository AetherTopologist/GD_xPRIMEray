This matrix tracks **what xPRIMEray has evidenced in this repository today** — not how it compares to Blender, Godot, laboratory instruments, or other tools on the Atlas map.

**The Atlas is a map of observation systems, not a ranking of technologies.** Maturity describes *evidence depth*, not quality or superiority.

## Maturity ladder

`Vision` → `Prototype` → `Experimental` → `Internal Validation` → `Public Demo` → `Research Ready` → `Production Ready`

Maturity applies per capability and describes available evidence, not quality or superiority. See the repository [Technology Landscape Methodology](../technology_landscape/landscape_methodology.md) for the evidence expectations behind each level.

A capability can be **Experimental** while another remains **Vision**. That is normal; the Atlas is a map in progress.

Protocol and measurement evidence is indexed under [Project Glowing Heart](README.md#relationship-to-project-glowing-heart).

## Reading boundary

This matrix follows the Atlas [reading boundary](README.md#reading-boundary). No row establishes parity, superiority, benchmark performance, or production readiness.
