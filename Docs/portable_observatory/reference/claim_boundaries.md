# Claim Boundaries

Prefer cautious research language. Correct or qualify any wording that overclaims.

---

## Forbidden or strongly qualified implications

| Implication | Prefer instead |
|-------------|----------------|
| Magenta is an outcome | Magenta is a **legacy fallback/presentation color**; only `ProbeOutcomeCode` / sealed outcome is authoritative |
| Nonzero film hits prove HitGeometry | Film hits are **pass-2 shading acceptance**; terminal class is pass-1 `ProbeOutcomeCode` |
| MaxStepsExhausted means never touched geometry | Terminal budget class under policy; **historical contact may have occurred** |
| Refinement guarantees truth | Deeper refinement = more **Transport Effort** under **numerical policy** |
| Path length is proper time | Path length (when recorded) is **scene-length** proxy |
| Step count is time or energy | Step count is **Transport Effort**, not time or energy |
| Field dial equals evaluated field magnitude | Field dial is a **control scale**; evaluated `field.magnitude` is **planned** |
| NormalRGB proves semantic geometry resolution | NormalRGB is a **visualization mapping**; needs HitGeometry + valid normals for orientation claims |
| Fixture PASS proves live runtime correctness | Fixture PASS is **recipe-bound**; ≠ free-roam qualification |
| Closure proves exotic topology | **Policy-relative closure** under a stated test |
| Cathedral / Region Probe proves wormholes | Semantic outcome classification under simulated transport |
| Simulated curvature equals physical gravity | **Simulated transport** / research hypothesis |
| Causal ordering exists when only processing order is recorded | Record **processing order** only; do not invent causal structure |

## Preferred vocabulary bank

Use freely:

- simulated transport
- numerical policy
- scene units
- policy-relative closure
- semantic outcome classification
- visualization mapping
- experimental fixture
- research hypothesis

---

## Doctrine checklist

- Display ≠ probe
- Plate color ≠ outcome code
- Deeper refinement ≠ greater truth
- Complete frame ≠ successful geometry resolution
- Viewport ≠ Observation Plate
- Display Mode ≠ Instrument
- Fixture PASS ≠ live free-roam qualification
