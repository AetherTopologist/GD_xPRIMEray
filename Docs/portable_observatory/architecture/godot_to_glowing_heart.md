# Godot to Glowing Heart

xPRIMEray hosts observations in more than one place:

| Host | Role |
|------|------|
| **Godot Transport Lens** | Interactive Scene → Plate → Inspector → Region Probe |
| **Project Glowing Heart** | Fixture protocols, difference packets, shared observer contracts, galleries |

The Portable Observatory lane uses **public vocabulary** so both hosts can narrate the same spine without pretending they share every UI widget.

---

## Shared ambitions

- Sealed observation frames and channel IDs
- Explicit claim boundaries on records
- Recipe-bound Evidence separate from free-roam exploration
- Display mappings named separately from instruments

## Do not collapse

| Godot-facing | Glowing Heart-facing |
|--------------|----------------------|
| Live film plate | Fixture browser / difference packet gallery |
| Region Probe keys | Headless qualification recipes |
| NormalRGB Display Mode | Channel registry / comparable channels when defined |
