# Fixture vs Live Runtime

| | **Experimental fixture / recipe** | **Live free-roam** |
|--|-----------------------------------|--------------------|
| Context | Fixed pose, policy, scene id | Operator-controlled |
| Verdict | PASS/FAIL under named recipe | Exploration only |
| Plate | Optional illustration | Primary interactive surface |
| Authority | Recipe + sealed records | Complete SNAPSHOT + sealed channels for local claims |

## Rules

1. A green fixture run does **not** certify the operator’s current live plate.
2. Live claims need Complete snapshot + matching context + named channels.
3. Gallery beauty stills are presentation unless sealed data is attached.
4. OI / Glowing Heart qualification is a **sibling** evidence lane—map carefully; do not silently equate.
